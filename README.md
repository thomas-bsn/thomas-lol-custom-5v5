# LoL Custom 5v5 — Frontend

Web interface for managing players and League of Legends custom 5v5 games.

## Features

- Player management
- Ranked and MMR visualization
- Balanced team generation
- Game management
- Match history

## Tech Stack

- React
- TypeScript
- Next.js
- Tailwind CSS

The frontend consumes the ASP.NET Core backend API and provides the interface for managing custom games.
